# SentinelX-AI — Supply Chain Risk Intelligence Platform

A full-stack AI-powered dashboard that helps organizations monitor and 
manage supplier risk in real time.

## Features
- **Risk Scoring Engine** — Computes a composite 0–100 risk score for 
  each supplier based on financial health, delivery delays, 
  geopolitical risk, and news sentiment.
- **Real-time Alerts** — Automatically flags high-risk suppliers and 
  generates actionable recommendations.
- **AI Chat Assistant** — Ask natural-language questions like 
  "which supplier is highest risk?" and get instant answers.
- **Interactive Map** — Visualize global supplier locations 
  color-coded by risk severity.
- **What-if Simulator** — Model disruption scenarios (port closures, 
  factory outages, sanctions) and see projected impact.

## Tech Stack
- Frontend: React + Vite
- Backend: FastAPI + SQLAlchemy
- Auth: JWT
- Visualization: Recharts
